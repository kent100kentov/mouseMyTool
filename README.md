# MagicTap / mouseMyTool

Нативная экспериментальная утилита macOS для левого клика лёгким касанием Apple Magic Mouse. Swift + AppKit, небольшой Objective-C мост. Apple Silicon (arm64), macOS 13+; фактически собрана и проверена на macOS 27.2. Совместимость со всеми версиями macOS и поколениями мыши **не подтверждена**.

## Чувствительность — новое в 0.1.2

В меню мыши откройте **«Чувствительность…»**. Есть режимы **«Быстрые касания»** (по умолчанию), **«Обычный»**, **«Осторожный»** и свои значения. Пять ползунков применяются сразу и сохраняются между запусками:

| Регулировка | Диапазон | Быстрые касания |
| --- | --- | --- |
| Минимальная длительность | 0–40 мс | 8 мс |
| Максимальная длительность | 100–600 мс | 350 мс |
| Допуск движения пальца | 1–15% поверхности | 7% |
| Допуск смещения курсора | 0–20 пт | 8 пт |
| Защитная задержка после отпускания | 0–60 мс | 12 мс |

Если быстрые tap пропускаются, попробуйте минимум **2–5 мс**. Если появились случайные клики — увеличьте минимум или выберите «Осторожный». Нулевые минимум и задержка доступны по выбору пользователя, но могут чаще пропускать шум или физический клик, поступивший позже. Это не регулировка силы нажатия: давление мышь здесь не измеряет.

Мелкое дрожание курсора в пределах допуска больше не отменяет касание. Учитывается общее смещение от начала касания, поэтому последовательность небольших перемещений не обходит защиту от движения. Прокрутка и физические нажатия по-прежнему отменяют tap. Настройки меняют распознавание без повторного запроса разрешений и без перезапуска приложения. После изменения уберите пальцы с поверхности для подготовки нового жеста.

Диагностика показывает причины отклонения касаний: слишком короткое/долгое, движение пальца/курсора, смещение при отпускании, край, несколько пальцев, физическое вмешательство. Счётчики не записывают координаты.

## Исправления 0.1.1

Исправлены отбрасывание одиночного касания после паузы и блокировка tap после обычного перемещения курсора. Перезагрузка macOS для этого исправления не нужна: завершите старую версию и замените приложение. После замены ad-hoc сборки macOS может потребовать повторно добавить приложение в разрешения.

## Установка

1. Скачайте `MagicTap-0.1.2-arm64.zip` из Releases и распакуйте.
2. Переместите `MagicTap.app` в `/Applications` (Программы), затем откройте.
3. Найдите значок мыши в строке меню. Функция изначально выключена.
4. Через меню разрешите **Универсальный доступ** (отправка клика) и **Мониторинг ввода** (контроль касаний и событий мыши). macOS может потребовать перезапуск приложения.
5. Нажмите «Проверить подключение и разрешения», включите «Клик касанием», уберите все пальцы с поверхности и легко коснитесь одним пальцем.
6. По желанию включите «Запускать при входе». Используется `SMAppService.mainApp`; если macOS просит одобрение, подтвердите в настройках объектов входа.

Сборка подписана локальной ad-hoc подписью, без Developer ID и нотарификации Apple. Если macOS блокирует запуск, используйте предусмотренное системой «Всё равно открыть» в разделе конфиденциальности и безопасности для этого приложения. Не требуется отключать SIP или Gatekeeper. Для широкого распространения нужна подпись Developer ID и нотарификация. Пересборка/перемещение может потребовать заново добавить приложение в разрешения.

## Поведение

- Одно касание в выбранном диапазоне длительности → левый клик после отпускания и выбранной защитной задержки. В режиме «Быстрые касания» это 8–350 мс и 12 мс задержки.
- Два последовательных касания → системная последовательность двойного клика. Сохраняются Shift/Control/Option/Command.
- Значительное движение пальца/курсора сверх выбранного допуска, края поверхности, несколько пальцев, долгое удержание, прокрутка и физические нажатия отменяют жест.
- Другой палец, постоянно лежащий на мыши, мешает распознаванию: текущая версия принимает только изолированный однопальцевый tap.
- Нет tap-and-drag и правого клика касанием. Штатные физические клики/прокрутка не подавляются.
- При включении может потребоваться одно касание для получения пустого кадра и подготовки распознавателя. Это защищает от пальца, уже лежавшего на мыши.
- «Клик касанием» выключает чтение касаний, мониторинг событий и отложенные клики. «Завершить» полностью закрывает приложение.

Пороги требуют подстройки и проверки на реальном устройстве; изменяются в окне чувствительности, профили находятся в `Sources/TapSettings.swift`. «Сила нажатия» не используется: ёмкостная площадь контакта не является измерением физического давления.

## Ограничение моделей

Автоматически принимается только известная сигнатура: внешний multitouch-девайс, family 112, driver 4, поверхность 5152×9056. Эта сигнатура документирована открытым проектом CommandPost для Magic Mouse первого поколения и обнаружена локальной диагностикой. Встроенный и внешний трекпады исключены. Lightning/USB-C модели с другой сигнатурой **пока не поддерживаются автоматически**: нужно сначала посмотреть диагностические параметры и подтвердить принадлежность устройства. Не расширяйте фильтр на «любое внешнее устройство»: так можно включить Magic Trackpad.

## Сборка и проверки

Нужны Xcode Command Line Tools или Xcode, без сторонних библиотек:

```sh
./scripts/build.sh
./scripts/test.sh
./scripts/test-ui.sh # в графической сессии macOS
./dist/MagicTap.app/Contents/MacOS/MagicTap --diagnose
```

`--diagnose` только проверяет символы и перечисляет свойства устройств, не запускает touch callbacks и не отправляет клики. `--smoke-test` открывает интерфейс с принудительно выключенной функцией и завершается через 2 секунды. Для него нужна обычная графическая сессия macOS.

Результат: `dist/MagicTap.app`. Команда сборки использует arm64, минимальную macOS 13, App Sandbox выключен. Для собственной подписи: `SIGN_IDENTITY='Developer ID Application: …' ./scripts/build.sh`; это не заменяет нотарификацию.

## Нагрузка и приватность

Нет периодического опроса и фоновой сети. Список устройств обновляется по уведомлениям IOKit с debounce 600 мс и после сна/возврата в пользовательскую сессию. Каждый кадр обрабатывает максимум 16 контактов. Обработчики приватного API копируют только необходимые поля; устаревшие кадры отменяют жест, а поколение подписки исключает отложенные кадры после остановки. Счётчики хранятся только в памяти. Записи клавиш, координат и журналов касаний нет. Измерения CPU/энергии при реальных касаниях ещё не проводились.

## Почему выбран приватный API

См. [RESEARCH.md](RESEARCH.md): сравнение AppKit, Quartz, IOHID и MultitouchSupport, ссылки и границы надёжности. См. [TESTING.md](TESTING.md): что фактически проверено и что остаётся проверить на мыши.
