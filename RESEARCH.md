# Исследование подходов — 8 ноября 2026

## Вывод

Tap-to-click Magic Mouse технически реализуем в обычном приложении macOS через приватный MultitouchSupport.framework и синтез пары CGEvent leftMouseDown/leftMouseUp. Это практический подход, используемый независимыми открытыми утилитами, но не гарантированный Apple стабильный интерфейс. Полностью поддерживаемого публичного решения для глобального чтения сырой поверхности Magic Mouse по изученным материалам не найдено. Сборку следует считать preview, пока не проверены callbacks, пороги и отсутствие ложных кликов на конкретной мыши.

## Методы

| Метод | Возможности | Решение |
| --- | --- | --- |
| AppKit NSTouch/NSEvent | Touch collections привязаны к представлению приложения; не дают документированного глобального потока сырой поверхности Magic Mouse | Не подходит для системной утилиты |
| Quartz CGEvent event tap | Обычные клики, движение и прокрутка; не сырой мультитач | Используется как listen-only монитор для отмены жестов |
| IOHIDManager input reports | Публичный доступ к обнаружению HID и отчётам; требуется разбор протокола конкретного устройства, а доступ к multitouch-отчётам через системный драйвер нельзя предполагать | Не выбран для чтения поверхности; IOKit используется только для подключения/отключения |
| MultitouchSupport.framework | Реальные контактные кадры; недокументированные ABI, состояния и идентификаторы | Выбран с динамической загрузкой, строгим фильтром устройств и отказом при недоступности символов |
| DriverKit/свой драйвер | Значительно более сложное распространение и взаимодействие с системным драйвером | Не оправдан для этой утилиты |

## Границы надёжности

`dlopen`/`dlsym` позволяют корректно отказать при отсутствии функций, но **не защищают от изменения ABI** при сохранении имён символов. Размер Contact 96 байт и смещение normalizedVector 32 проверяются при компиляции; это не runtime-проверка ABI Apple. Для этого нужны реальные кадры после обновлений macOS. Проверки диапазонов контактов уменьшают риск неверного распознавания, но не делают приватный API безопасным при произвольной смене ABI.

Приложение удерживает CFArray со ссылками на устройства до остановки, снимает callbacks, отбрасывает события старого поколения, остаётся загруженным вместе с framework до завершения процесса. Сон/выход из активной сессии останавливает обработку, пробуждение переоткрывает устройства. На отключении отменяются ожидающие клики; новый scan происходит через 600 мс. Если подходящая мышь не обнаружена, приложение показывает это в меню и остаётся ждать уведомления подключения.

Разрешения проверяются перед запуском и перед отправкой клика. Недоступный event tap запрещает работу. Отзыв разрешений и реальные особенности private callbacks требуют ручного тестирования. Системные ограничения защищённых экранов нельзя обойти этим приложением; работа на login screen не предполагается.

Mac App Store требует публичных API (2.5.1), поэтому текущий подход предназначен для прямого распространения. Не нужны root, kext и отключение SIP. Отсутствие App Sandbox выбрано для доступа к устройствам и системному вводу; не следует утверждать, что один лишь вызов dlopen всегда запрещён sandbox.

## Первичные источники

- [Apple NSTouch](https://developer.apple.com/documentation/appkit/nstouch) — модель привязки касаний к view.
- [Apple IOHIDManager](https://developer.apple.com/documentation/iokit/iohidmanager_h) — публичные callbacks устройств и отчётов.
- [Apple CGPreflightListenEventAccess](https://developer.apple.com/documentation/coregraphics/cgpreflightlisteneventaccess()) — статус разрешения мониторинга ввода.
- [Apple SMAppService](https://developer.apple.com/documentation/servicemanagement/smappservice) — современная регистрация запуска при входе.
- [Apple App Review Guidelines 2.5.1](https://developer.apple.com/app-store/review/guidelines/#software-requirements) — использование публичных API.
- [M5MultitouchSupport](https://github.com/mhuusko5/M5MultitouchSupport) — авторский проект глобального чтения multitouch.
- [magic-mouse-touch](https://github.com/Raphe-dev/magic-mouse-touch) — практическая реализация tap-to-click через private framework. Не является гарантией Apple и не использована как готовая зависимость.
- [Описание ABI Contact](https://github.com/lauschue/Remotastic/blob/main/MultitouchSupport.h) — reverse-engineered структура и объявления функций.
- [CommandPost mousezoom.lua](https://github.com/CommandPost/CommandPost/blob/develop/src/plugins/finalcutpro/timeline/mousezoom.lua) — строгая сигнатура Magic Mouse первого поколения.

Код проекта написан отдельно; внешние проекты служат свидетельствами реализуемости и справкой по недокументированному интерфейсу.
