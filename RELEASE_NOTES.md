Первая экспериментальная сборка MagicTap для Apple Silicon (arm64), macOS 13+.

- Левый клик коротким однопальцевым касанием Magic Mouse.
- Включение/выключение через строку меню, запуск при входе через SMAppService.
- Защита от прокрутки, движения, долгих/многопальцевых касаний и физических кликов.
- Меню разрешений, диагностика, восстановление подписки после уведомлений подключения и сна.

**Совместимость:** автоматически выбирается только известная сигнатура Magic Mouse первого поколения (family 112, driver 4, 5152×9056). Другие сигнатуры Lightning/USB-C не включены без проверки. Используется приватный API Apple, который может измениться после обновления macOS.

**Проверено:** сборка на macOS 27.2 arm64, 16 тестов на искусственных кадрах, загрузка символов, перечисление/фильтрация устройств, запуск интерфейса с выключенной функцией, целостность подписи. **Реальные касания и отправка кликов на оборудовании ещё не проверены**: Accessibility/Input Monitoring не были выданы. Автозапуск и нагрузка при касаниях тоже требуют ручной проверки.

Скачайте `MagicTap-0.1.0-arm64.zip`, распакуйте, переместите приложение в Программы. Через значок мыши выдайте Универсальный доступ и Мониторинг ввода, при необходимости перезапустите и включите «Клик касанием».

Приложение подписано ad-hoc, без Developer ID/нотарификации. Если macOS блокирует запуск, используйте системное «Всё равно открыть» для этого приложения. Подробности, ограничения и план проверки — в README.md, RESEARCH.md и TESTING.md репозитория. SHA256SUMS.txt позволяет проверить скачанный архив.
