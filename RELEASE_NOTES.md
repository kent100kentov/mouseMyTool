Добавлен правый клик касанием Magic Mouse.

- Касание левой половины — левый клик; правой — правый клик для контекстного меню.
- Все пять настроек скорости и чувствительности общие для обеих кнопок.
- В окне «Чувствительность…» появился флажок правого клика; по умолчанию включён. При выключении вся поверхность даёт левый клик.
- Сторона определяется в начале касания; сдвиг при отпускании не меняет кнопку. Чередование кнопок не образует двойной клик.
- Диагностика отдельно считает левые и правые клики.

**Значения по умолчанию как на выбранном скриншоте:** минимум 2 мс, максимум 350 мс, движение пальца 7%, смещение курсора 8 пт, задержка 8 мс. Ваши сохранённые значения сохраняются; для применения исходных выберите «Быстрые касания».

Установка: завершите старую версию, распакуйте `MagicTap-0.1.3-arm64.zip`, замените приложение в Программах и откройте. Сборка подписана ad-hoc; после замены macOS может потребовать повторно выдать Универсальный доступ и Мониторинг ввода.

Проверено: 189 автоматических проверок распознавания, настроек, кнопок, последовательностей, нативного окна и создания событий без их отправки; arm64-сборка, запуск окон с выключенной функцией, подпись. Правый клик на физической мыши ещё требует пользовательской проверки.

Ограничения: приватный API Apple, известная сигнатура Magic Mouse первого поколения (family 112, driver 4, 5152×9056), macOS 13+, без Developer ID и нотарификации. Для других поколений совместимость не заявлена.
