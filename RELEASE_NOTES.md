Исправление распознавания в MagicTap для Apple Silicon.

- Исправлен пропуск одиночного tap после паузы больше 0,5 секунды.
- Перемещение курсора до касания больше не блокирует следующий tap; движение во время касания по-прежнему отменяет его.
- После подтверждённой пустой поверхности допускается контакт, у которого отсутствует краткий кадр начала (state 3).
- Диагностика показывает число распознанных tap, пустых/невалидных кадров и агрегированные состояния контактов. Координаты не сохраняются.

**Установка обновления:** в меню старой версии выберите «Завершить MagicTap», распакуйте `MagicTap-0.1.1-arm64.zip` и замените приложение в Программах. Запустите снова, проверьте разрешения и включите «Клик касанием». Уберите пальцы, затем сделайте несколько лёгких касаний. Перезагрузка Mac для исправления не требуется. Из-за ad-hoc подписи macOS может потребовать заново добавить приложение в разрешения.

**Проверено:** 26 автоматических проверок распознавателя, arm64-сборка, запуск интерфейса с принудительно выключенной функцией, подпись приложения. Работа исправленных жестов и отправка кликов на физической мыши пока не подтверждены.

Ограничения preview сохраняются: приватный API Apple, известная сигнатура Magic Mouse первого поколения (family 112, driver 4, 5152×9056), macOS 13+, сборка без Developer ID и нотарификации. Для других моделей совместимость не заявлена.
